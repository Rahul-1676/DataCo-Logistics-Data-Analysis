# Logistics Data Analytics Internship

## About the Project
This repository contains my work and practical assignments completed during the Logistics Data Analytics Internship. The project focuses on analyzing logistics and supply chain data using Python and its data analysis libraries.

## Week 1: Data Collection and Cleaning Strategies

The first week's task focused on exploring, cleaning, transforming, and preparing the DataCo Smart Supply Chain Dataset for analysis.

### Objectives
- Understand the structure of logistics data.
- Identify and handle missing values.
- Check for duplicate records.
- Perform data type conversion.
- Calculate and validate shipping duration.
- Analyze delivery performance.
- Create visualizations to understand logistics data.

### Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

### Key Findings
- Original dataset: 180,519 rows and 53 columns.
- Final cleaned dataset: 180,519 rows and 55 columns.
- Remaining missing values: 0.
- Duplicate rows: 0.
- Late deliveries: 57.28%.
- Early deliveries: 24.02%.
- On-time deliveries: 18.70%.

# Week 2 – Exploratory Data Analysis (EDA)

## Project Overview
This week focuses on performing Exploratory Data Analysis (EDA) on the DataCo Smart Supply Chain Dataset. The objective is to understand the dataset, identify patterns and relationships between variables, and extract meaningful insights using Python.

## Tasks Completed
- Explored the cleaned dataset using Pandas.
- Generated descriptive statistics.
- Performed correlation analysis.
- Created a correlation heatmap.
- Created a histogram to understand shipping duration.
- Used a box plot to examine the distribution of shipping duration.
- Created scatter plots to study relationships between variables.
- Interpreted each visualization and documented the findings.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Findings
- Shipping duration has a very strong positive correlation with actual shipping days.
- Shipping duration and scheduled difference show a positive relationship.
- Sales and shipping duration have almost no linear correlation.
- The visualizations help identify patterns in shipping performance and sales-related data.

## Project Files
- `notebook/` – Jupyter Notebook containing the analysis.
- `visualizations/` – Generated graphs and charts.
- `report/` – Detailed Week 2 project report.

## Conclusion
The analysis provided a better understanding of the supply chain dataset through statistical exploration and data visualization. It also helped develop practical skills in data analysis, interpretation, and presenting insights.
