# Week 1 – Data Cleaning and Preprocessing

## Project Overview
Week 1 focused on understanding, cleaning, and preprocessing the DataCo Smart Supply Chain Dataset. The main objective was to improve data quality and prepare a reliable dataset for further analysis.

## Tasks Completed
- Loaded and explored the dataset using Pandas.
- Examined dataset dimensions, column names, and data types.
- Identified missing values and duplicate records.
- Removed columns with excessive missing values.
- Handled missing values in customer-related columns.
- Converted date columns into appropriate datetime formats.
- Created a new feature called `Shipping Duration`.
- Compared calculated shipping duration with actual shipping days.
- Analyzed delivery performance using shipping status.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
**DataCo Smart Supply Chain Dataset**

The dataset contains order, customer, product, sales, and shipping-related information.

## Key Findings
- Original dataset contained 180,519 records and 53 columns.
- Columns with excessive missing values were removed.
- Remaining missing values were handled appropriately.
- Final cleaned dataset contained 180,519 records and 55 columns.
- No missing values or duplicate rows remained after preprocessing.
- Shipping status was classified into Early, On Time, and Late categories.

## Project Files
- `notebook/` – Jupyter Notebook containing data cleaning and preprocessing.
- `visualizations/` – Graphs generated during the analysis.
- `report/` – Detailed Week 1 project report.

## Conclusion
Week 1 provided practical experience in data cleaning, preprocessing, feature creation, and data validation. The cleaned dataset serves as the foundation for the Exploratory Data Analysis performed in Week 2.
